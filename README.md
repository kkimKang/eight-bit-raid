# 8-BIT RAID

워크래프트 3 유즈맵 8 Bit Raid의 핵심 루프를 브라우저용 오리지널 8비트 레이드로 재현한 웹게임입니다. 타사 캐릭터·보스 IP와는 무관합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다.

## 조작 (1P)

- 이동: 방향키
- 점프: `Z` (길게 누르면 더 높이)
- 공격: `X`
- 스킬: `C` / `S` / `D`
- 음소거: `M`

2P는 `WASD` + `F` 점프 + `G` 공격 + `H`/`J`/`K` 스킬입니다. 3~4P는 게임패드를 사용합니다.
